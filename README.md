# Лабораторная работа № 5
## Разработка и интеграция модулей проекта

### Вариант 1
Даны две матрицы натуральных чисел размером не более 10×10. Для каждой матрицы нужно найти номера столбцов, все элементы которых кратны 5 или 7. Если подходящих столбцов нет, вывести сообщение. Проверка столбца оформлена отдельной функцией `is_valid_column(column)`.

### Структура проекта
- `input_module.py` — ввод матриц и проверка введённых данных.
- `processing.py` — проверка столбцов и поиск подходящих номеров.
- `output.py` — вывод матриц и результатов.
- `main.py` — связывает модули и запускает программу.

### Запуск
Требуется Python 3.10 или новее. В терминале из папки проекта выполните:

```bash
python main.py
```

В Windows также можно использовать:

```powershell
py main.py
```

### Командная разработка
Рекомендуемые ветки:
- `feature/input-module`
- `feature/processing`
- `feature/output`
- `feature/main-integration`

Изменения интегрируются в `main` через Pull Request после проверки другим участником команды.
